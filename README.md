# QuizForge

Responsive, accessible, full-stack assessment platform for teachers, students, and independent learners.
**Status:** Stage S01 (repository bootstrap). No product features yet.

- Requirements: [`docs/PRODUCT_SPEC.md`](docs/PRODUCT_SPEC.md)

- Coding agents: start with [`AGENTS.md`](AGENTS.md), then `agent/rules/` and `agent/skills/`.

## Prerequisites

- Node.js 22 LTS
- pnpm 10 (`corepack enable` will pick up the version from `package.json`)
- Docker (for the local PostgreSQL database)

## Local setup

```bash
pnpm install
cp .env.example .env          # local-development placeholders only
pnpm db:up                    # PostgreSQL via Docker Compose
pnpm --filter @quizforge/api prisma:generate
pnpm dev                      # web: http://localhost:5173  api: http://localhost:3000
```

- API health: `GET http://localhost:3000/api/v1/health` (liveness), `/api/v1/health/ready` (database check)
- OpenAPI docs: `http://localhost:3000/api/docs`

## Commands

| Command                                 | Purpose                                                           |
| --------------------------------------- | ----------------------------------------------------------------- |
| `pnpm dev`                              | Run API and web in watch mode                                     |
| `pnpm build`                            | Build all workspaces                                              |
| `pnpm lint`                             | ESLint across the repo                                            |
| `pnpm typecheck`                        | `tsc --noEmit` in every workspace                                 |
| `pnpm test`                             | Vitest (web, validation) and Jest/Supertest (api)                 |
| `pnpm format` / `pnpm format:check`     | Prettier                                                          |
| `pnpm --filter @quizforge/web test:e2e` | Playwright smoke test (needs `pnpm exec playwright install` once) |

## Architecture summary

- `apps/web`: React, Vite, React Router, TanStack Query, Tailwind CSS v4, shadcn/ui-ready (`components.json`, `cn` helper).
- `apps/api`: NestJS modular monolith under `/api/v1`, Swagger at `/api/docs`, Prisma (PostgreSQL) for server-only data access.
- `packages/shared-types`: public contracts. `packages/validation`: Zod schemas. Both are consumed as TypeScript source for now.
- Database models and migrations start in S02.

## Troubleshooting

- **`pnpm install --frozen-lockfile` fails in CI:** commit `pnpm-lock.yaml` generated by your first local `pnpm install`.
- **Prisma client types missing:** run `pnpm --filter @quizforge/api prisma:generate`.
- **Web shows "API: unreachable":** start the API (`pnpm dev`) and check `API_PORT` / the Vite proxy target (`http://localhost:3000`).
- **Port 5432 in use:** change `POSTGRES_PORT` and `DATABASE_URL` in `.env`.
- **`pnpm` blocks build scripts:** the allow-list is in the root `package.json` (`pnpm.onlyBuiltDependencies`).
