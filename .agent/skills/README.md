# Agent Skill Playbooks

These are project-specific procedural skills, not automatically installed tools. An agent should read the relevant skill before starting a task.

- `feature-implementation.md`: scope a feature and implement a safe vertical slice.
- `markdown-parser.md`: build and validate deterministic Markdown imports.
- `assessment-integrity.md`: handle tests, attempts, grading, and publication invariants.
- `review-and-release.md`: validate PRs and prepare a release.

Use with `AGENTS.md` and `agent/rules/*.md`; rules take precedence over convenience.
